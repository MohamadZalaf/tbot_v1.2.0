## 🎯 الميزات الرئيسية

### 1. 🔐 حماية بكلمة مرور
- حماية الوصول لواجهة التحكم
- حماية إضافية لإدارة المستخدمين والإعدادات
- كلمة مرور الواجهة: `041768454`

### 2. 👥 إدارة المستخدمين المتقدمة
- **زر عدد المستخدمين**: يعرض العدد الحالي مع إمكانية النقر عليه
- **حماية بكلمة مرور**: يطلب كلمة المرور عند النقر على زر عدد المستخدمين
- **نافذة إدارة المستخدمين**: تعرض قائمة بجميع المستخدمين مع:
  - معرف المستخدم
  - اسم المستخدم (@username)
  - الاسم الكامل
  - حالة المستخدم (نشط/محظور)
  - تاريخ التسجيل
- **أزرار الحظر**: 
  - 🚫 **حظر المستخدم**: حظر المستخدم المحدد
  - ✅ **إلغاء حظر المستخدم**: إلغاء حظر المستخدم المحدد
- **تحديث تلقائي**: تحديث قائمة المستخدمين كل 5 ثوان

### 3. ⚙️ نافذة الإعدادات المتقدمة
- **زر الإعدادات**: في أعلى يسار الواجهة (⚙️)
- **حماية بكلمة مرور**: يطلب كلمة المرور للوصول للإعدادات
- **واجهة مبوبة** تحتوي على:

#### تبويب Configurations:
##### قسم إدارة مفاتيح Gemini API:
- **عرض المفاتيح**: قائمة بجميع مفاتيح API الحالية (مقنعة للأمان)
- **➕ إضافة مفتاح**: إضافة مفتاح API جديد
- **✏️ تحرير**: تحرير المفتاح المحدد
- **🗑️ حذف**: حذف المفتاح المحدد (مع حماية من حذف المفتاح الوحيد)
- **🔍 فحص المفاتيح**: فحص حالة جميع المفاتيح مع تمييز لوني:
  - 🟢 **أخضر**: المفتاح يعمل بشكل طبيعي
  - 🔴 **أحمر**: المفتاح منتهي الرصيد أو يحتوي على خطأ
  - 🟡 **أصفر**: مكتبة Gemini غير متوفرة

##### قسم إعدادات MT5:
- **رقم الحساب**: حقل لإدخال رقم حساب MT5
- **كلمة المرور**: حقل لإدخال كلمة مرور MT5 (مخفية)
- **نوع الحساب**: حقل لإدخال نوع/خادم الحساب
- **💾 حفظ إعدادات MT5**: حفظ الإعدادات
- **🔗 اختبار الاتصال**: اختبار الاتصال الفعلي بـ MT5

#### تبويب Users:
- نفس نافذة إدارة المستخدمين داخل الإعدادات
- جميع وظائف الحظر وإلغاء الحظر متوفرة

### 4. 🔧 النظام المدمج الكامل
- **لا ملفات خارجية**: جميع أكواد البوت مدمجة في الواجهة
- **لا حاجة لـ tbot_v1.2.0.py**: الكود مدمج بالكامل
- **لا حاجة لـ config.py**: الإعدادات مدمجة ومحفوظة في ملف منفصل
- **لا حاجة لـ icon.ico**: الأيقونة مدمجة كـ base64
- **ملفات JSON محفوظة**: نظام ملفات JSON الأصلي محفوظ للمستخدمين

### 5. 🛠️ حل مشكلة إعادة التشغيل
- تم إصلاح المشكلة التي كانت تسبب إعادة تشغيل الـ exe عند الضغط على "تشغيل البوت"
- البوت الآن يعمل داخل الواجهة مباشرة دون إعادة تشغيل

## 🎮 طريقة الاستخدام

### 1. تشغيل الواجهة:
1. شغل الملف التنفيذي `TradingBotUI_v1.2.0.exe`
2. أدخل كلمة المرور: `041768454`
3. ستظهر لوحة التحكم الرئيسية

### 2. إدارة المستخدمين:
1. انقر على زر "👥 عدد المستخدمين" في أعلى يمين الواجهة
2. أدخل كلمة المرور عند الطلب
3. ستظهر نافذة إدارة المستخدمين مع قائمة كاملة
4. حدد مستخدم واستخدم أزرار الحظر/إلغاء الحظر

### 3. الوصول للإعدادات:
1. انقر على زر "⚙️" في أعلى يسار الواجهة
2. أدخل كلمة المرور عند الطلب
3. ستظهر نافذة الإعدادات مع التبويبات

### 4. إدارة مفاتيح Gemini API:
1. افتح الإعدادات → تبويب Configurations
2. في قسم "إدارة مفاتيح Gemini API":
   - أضف مفاتيح جديدة
   - حرر المفاتيح الموجودة
   - احذف المفاتيح غير المرغوبة
   - افحص حالة جميع المفاتيح

### 5. إعدادات MT5:
1. افتح الإعدادات → تبويب Configurations
2. في قسم "إعدادات تسجيل الدخول MT5":
   - أدخل رقم الحساب
   - أدخل كلمة المرور
   - أدخل نوع الحساب
   - احفظ الإعدادات
   - اختبر الاتصال

## 🚨 استكشاف الأخطاء

### مشاكل شائعة وحلولها:

#### 1. "البوت لا يبدأ":
- تأكد من صحة BOT_TOKEN في الإعدادات
- تحقق من اتصال الإنترنت
- راجع ملف bot.log للتفاصيل

#### 2. "خطأ في مفاتيح API":
- تحقق من صحة مفاتيح Gemini API
- استخدم زر "فحص المفاتيح" للتأكد من الحالة
- أضف مفاتيح إضافية إذا لزم الأمر

#### 3. "فشل اتصال MT5":
- تأكد من تثبيت MetaTrader5
- تحقق من صحة بيانات الحساب
- استخدم زر "اختبار الاتصال"

#### 4. "المستخدمون لا يظهرون":
- تأكد من وجود مجلد trading_data/users/
- تحقق من صلاحيات الكتابة في المجلد
- استخدم زر "تحديث" لإعادة تحميل البيانات
